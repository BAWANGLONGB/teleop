>
> 本页是快速清单，不替代完整现场 SOP。首次部署、网络设置、实机验收和故障排查必须使用

## 2. 开发流程（简版）

1. 先定位层次：XR 映射与 IK 改 `common/`，Marvin SDK 与调度改 `hardware/`，入口改 `scripts/`，行为验证改 `tests/`。
2. 只做一个可验证的小改动，同步增加或更新测试。
3. 保持安全约束：SDK 只由一个 I/O 线程访问；ROS2 只观测；内部用 SI 单位；启动采用实测关节位置；FAULT 不自动清除。
4. 运行自动测试：

   ```bash
   PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 \
     python -m pytest -q tests/test_marvin_hardware.py tests/test_marvin_mujoco_model.py
   ```

5. 涉及 XR、IK、坐标、限幅或回位时，连接 PICO 后先做 MuJoCo 验证：

   ```bash
   python scripts/simulation/teleop_marvin_mujoco.py --scale-factor 0.5
   ```

6. 检查 `git diff --check` 和 `git diff`，记录测试结果。参数、按键行为或操作顺序变更时，同步修改 README 和对应的 `docs/` 文档。

自动测试和仿真通过只证明软件基线可用，不代表已通过实机验收。普通开发和 CI 不得运行带
`--enable-hardware` 的入口。

## 3. 操作指南（简版）

### 3.1 启动 PICO 数据链路

1. 在独立终端启动 PC Service：

   ```bash
   bash /opt/apps/roboticsservice/runService.sh
   ```

2. 在 PICO 的 XRoboToolkit 中填写主机 Wi-Fi IPv4，确认 `Network = WORKING`。
3. 开启 `Head`、`Controller` 和 `Send`，保持 `Switch w/ A Button` 关闭。
4. 需要时用下面的命令确认 PC Service 正在监听：

   ```bash
   pgrep -af RoboticsServiceProcess
   ss -lnt | grep -E ':(63901|60061)\b'
   ```

### 3.2 日常默认：先运行仿真

```bash
python scripts/simulation/teleop_marvin_mujoco.py --scale-factor 0.5
```

- 左右 Grip 分别控制左右臂。
- 松开 Grip 后，仿真中对应手臂返回放松姿态。
- 双 Grip 松开时，`A`/`A` 采集自然下垂与水平前伸两点，`B` 取消本轮标定。
- 正常退出使用 `Ctrl+C`，延迟日志保存到 `logs/`。

### 3.3 实机之前：只读检查

保持机械臂下伺服或现场规定的安全只读状态：

```bash
python scripts/hardware/inspect_marvin_state.py --duration-s 10
```

10 秒检查通过后，现场验收再执行 30 分钟基线：

```bash
python scripts/hardware/inspect_marvin_state.py --duration-s 1800
```

该入口不切换模式、不修改参数、不发送运动目标。

### 3.4 实机低速遥操

仅当完整 Go/No-Go 已通过，真机型号、A/B 映射、Tool 和物理急停已确认，工作区已清空且急停观察员在场时才可执行：

```bash
python scripts/hardware/teleop_marvin_hardware.py \
  --enable-hardware \
  --confirmed-estop \
  --confirmed-joint-mapping \
  --confirmed-robot-model "从铭牌和控制器读取的准确型号"
```

- 启动和按 Grip 前保持双 Grip 松开；首次只做单臂、TCP 小于 5 cm 的空载测试。
- 真机中松开对应 Grip 后，手臂受限返回本次启动的实测姿态；等待返回完成后再停机。
- 正常停止：松开双 Grip → 等待进入 ARMED → `Ctrl+C` → 确认程序请求 `state=0` 并输出日志路径。
- 出现失控趋势、碰撞风险或进程无响应：先按物理急停，不要依赖 PICO 按键或 `Ctrl+C`。

## 4. 结果检查

- 仿真日志：`logs/marvin_latency_*.csv` 和 `.summary.json`。
- 实机日志：`logs/marvin_hardware_*.jsonl` 和 `.summary.json`。
- 标定数据：`logs/marvin_calibration_*.csv` 和 `.metadata.json`。
- 日志、完整启动命令、本次参数与异常现象应一起归档。
