使用说明

01PICO 端连接

  1. 让 PICO 与采集机 Wi-Fi 处于同一局域网，并保持头显和双手柄唤醒。
  2. 打开 XRoboToolkit，进入 Data & Control → PC Service → Enter。
  3. 填写采集机的 Wi-Fi IPv4，例如 192.168.120.115；不要填写 127.0.0.1 或 Marvin 地址。
  4. 确认 Network=WORKING，打开 Head、Controller 和 Send，关闭 Switch w/ A Button。
  5. 返回 UI，确认 PICO 显示“已连接”；异常时检查 63901、60061 和实时监督提示。

02数采操作流程

  1. 确认 PICO、机械臂、夹爪和相机状态，完成现场安全检查。
  2. 填写任务名称、采集员和机器人型号，按需选择视觉、分辨率及最长时长。
  3. 点击“启动设备”，等待设备就绪后按 Enter 或点击“开始录制”。
  4. 点击“停止并保存”或按 Esc 完成本段录制；最后点击“停止设备”。
  5. 在“数据集”搜索、查看、导出或将 Episode 移入回收站。

安全提示 UI 停止不是急停；出现异常运动时立即使用物理急停。
