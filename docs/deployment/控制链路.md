• Marvin 控制链路如下：

  hardware.py
    └─ 创建 MarvinSdkAdapter + MarvinHardwareTeleopController
        └─ controller.run()
            ├─ prepare_hardware()       启动与模式配置
            ├─ execute_control_cycle()  50 Hz 实时控制
            └─ shutdown_hardware()      空闲与释放

  ### 1. 启动链路

  src/xr_marvin_teleop/cli/hardware.py:310 创建适配器和控制器，最后调用 teleop_controller.run()。

  controller.run()
    → controller.prepare_hardware()
    → adapter.connect()
    → Marvin_Robot.connect("192.168.1.190")
    → libMarvinSDK.so::OnLinkTo(...)

  marvin.py 加载厂商 SDK 的过程：

  validate_vendor_driver_dependency()
    → 检查 fx_robot.py
    → 检查 libMarvinSDK.so
    → 检查 robot.ini
    → 检查 UseEMG == 1
    → 检查双臂 JointPIDCtlType == 1

  load_vendor_sdk()
    → import SDK_PYTHON.fx_robot
    → 创建 Marvin_Robot()

  对应位置：

  - src/xr_marvin_teleop/adapters/marvin.py:14
  - vendor/marvin/tj_fx_robot-master/SDK_PYTHON/fx_robot.py:322

  连接成功后，prepare_hardware() (src/xr_marvin_teleop/control/controller.py:325) 依次执行：

  读取 XR 初始状态
    → 要求 Grip/Trigger 已释放
    → adapter.connect()
    → 检查 SDK 版本
    → wait_for_fresh_feedback()
    → 确认无错误且机器人低速静止
    → configure_control_parameters()

         └─ set_tool()
    → enter_joint_impedance()
         ├─ set_state(A/B, state=3)
         └─ set_impedance_type(A/B, type=1)
    → enable_pd_feedforward()
    → 发送当前位置作为首个目标

  ### 2. 实时控制链路

  默认以 50 Hz 执行 execute_control_cycle() (src/xr_marvin_teleop/control/controller.py:793)：

  XR/PICO 手柄状态
    → xr_client.read_snapshot()
    → adapter.read_state()
    → 健康检查 / 反馈帧递增检查
    → OpenXR 位姿转换到 Marvin 坐标系
    → Grip 是否按下
    → FK 获取当前末端位姿
    → XrTargetMapper 计算目标末端位姿
    → IK 计算左右臂目标关节角
    → 关节速度限幅
    → controller._send_joint_command()
    → adapter.send_joint_command()
    → 厂商 SDK
    → libMarvinSDK.so
    → Marvin 控制器

  核心命令路径：

  controller._compute_q_command()
    → controller._compute_arm_q_command()
        → kinematics.fk_world()
        → pose_mapper.map_arm()
        → kinematics.ik_world()
    → controller._limit_joint_command_step()
    → controller._send_joint_command(q_rad)
    → adapter.send_joint_command(q_rad)

  适配器发送阶段会完成单位转换：

  14 关节弧度 q_rad
    → np.rad2deg()
    → set_joint_cmd_pose("A", 前7轴)
    → set_joint_cmd_pose("B", 后7轴)
    → send_cmd()

  对应位置：

  - IK 与目标生成：src/xr_marvin_teleop/control/controller.py:490
  - 命令发送入口：src/xr_marvin_teleop/control/controller.py:762
  - SDK 命令事务：src/xr_marvin_teleop/adapters/marvin.py:365
  - 双臂关节下发：src/xr_marvin_teleop/adapters/marvin.py:383

  ### 3. 状态反馈链路

  libMarvinSDK.so
    → fx_robot.Marvin_Robot.subscribe(DCSS)
    → adapter.read_state()
    → 解析左右臂反馈
    → 角度 deg → rad
    → MarvinRobotState
    → controller 健康检查和下一周期 IK

  反馈包括：

  - frame_serial：判断反馈是否持续更新
  - q_rad：当前关节位置
  - dq_rad_s：当前关节速度
  - arm_state：运行状态
  - impedance_type：阻抗模式
  - error_code：错误码
  - low_speed：低速/静止标志

  见 src/xr_marvin_teleop/adapters/marvin.py:283。

  ### 4. 异常与停止

  任何周期出现以下情况都会抛出异常并进入 finally 关闭：

  机器人错误码非零
  反馈连续 3 周期不更新
  双臂退出 state=3 / impedance type=1
  SDK setter 或 send_cmd 失败
  命令缓冲区忙超过 20 ms

  关闭链路：

  controller.shutdown_hardware()
    → adapter.set_idle()
        → set_state(A/B, state=0)
        → send_cmd_wait_response()
    → 等待反馈 arm_state == (0, 0)
    → adapter.release()
        → Marvin_Robot.release_robot()

  因此两个文件的职责边界很清楚：

  controller.py：决定“机器人应该去哪里”
  marvin.py：负责“如何安全地把命令交给厂商 SDK”
