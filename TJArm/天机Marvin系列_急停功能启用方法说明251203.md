## 一、Linux 系统下通过 SSH 远程连接启用急停

![章节页](<天机Marvin系列_急停功能启用方法说明251203_assets/page-03.jpg>)

### 1-1 用户登录以及密码输入

通过 SSH 远程连接主机并修改参数文件：

1. 输入以下命令。默认 IP 地址为 `192.168.1.190`；如果客户修改过地址，请使用实际 IP。

   ```bash
   ssh root@192.168.1.190
   ```

2. 输入密码：`passwd`。完成后即可进入控制器主板系统。

![用户登录以及密码输入](<天机Marvin系列_急停功能启用方法说明251203_assets/page-04.jpg>)

### 1-2 查询 `robot.ini` 路径

登录后，按以下路径找到 `robot.ini`：

```text
/home/FUSION/Config/cfg/robot.ini
```

![查询 robot.ini 路径](<天机Marvin系列_急停功能启用方法说明251203_assets/page-05.jpg>)

### 1-3 修改参数、保存并退出

1. 使用 `nano` 打开 `robot.ini`。
2. 找到 `UseEMG` 参数，将其值从 `0` 改为 `1`。
3. 保存修改并退出编辑模式。
4. 单独断电重启控制器，然后测试急停功能是否启用成功。

![修改参数、保存并退出](<天机Marvin系列_急停功能启用方法说明251203_assets/page-06.jpg>)

## 二、Windows 系统下通过 `fx_marvin_tool` 启用急停

![章节页](<天机Marvin系列_急停功能启用方法说明251203_assets/page-07.jpg>)

### 2-1 下载并解压 `fx_marvin_tool`

1. 如果没有上位机软件，可在开源仓库的 Releases 页面下载最新版本。原文演示使用 `100334` 版本。
2. 解压后，打开其中的 `MarvinUpdateTool`。

原文给出的开源地址：  
<https://github.com/cynthia-you/TJ_FX_ROBOT_CONTRL_SDK/tree/%E4%B8%8A%E4%BD%8D%E6%9C%BA%E8%BD%AF%E4%BB%B6MARVIN_APP>

![下载并解压 fx_marvin_tool](<天机Marvin系列_急停功能启用方法说明251203_assets/page-08.jpg>)

### 2-2 打开 `MarvinUpdateTool` 下载参数文件

1. 打开 `MarvinUpdateTool` 后连接机器人，默认 IP 为 `192.168.1.190`。
2. 点击“当前版本”，检查是否已连接机器人：未连接显示 `0`，已连接显示版本号。
3. 确认连接后，点击“获取参数文件”。软件会在当前文件夹生成 `tmp_robot.ini`。

> 获取参数时会覆盖同名文件；如需保留原文件，请先重命名。

![下载参数文件](<天机Marvin系列_急停功能启用方法说明251203_assets/page-09.jpg>)

### 2-3 修改参数文件

1. 打开 `tmp_robot.ini`。
2. 找到 `UseEMG`，将其值从 `0` 改为 `1`。
3. 保存文件并退出。

![修改参数文件](<天机Marvin系列_急停功能启用方法说明251203_assets/page-10.jpg>)

### 2-4 上传修改后的参数文件

1. 将刚修改的 `tmp_robot.ini` 上传到控制器，点击“上传参数文件”即可。
2. 确认所选文件路径确实指向刚修改的文件，否则配置不会生效。存在多个 `marvin_tool` 版本时需特别检查路径，因为不同版本上传文件时会共用同一个路径。
3. 单独断电重启控制器，然后测试急停功能是否启用成功。

![上传修改后的参数文件](<天机Marvin系列_急停功能启用方法说明251203_assets/page-11.jpg>)
