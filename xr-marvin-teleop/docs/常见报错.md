# 常见报错

先看 traceback 的最后一个异常及其前面的设备日志。现场出现异常运动时先使用物理急停，
排障命令不能替代急停；重新启动前按[操作指南](操作指南.md)检查设备状态。

| 报错或现象 | 检查与处理 |
| --- | --- |
| `release both Grip controls before enabling Marvin` | 松开左右 Grip 后重试；这是手柄输入检查，与 DAS 插拔无关。启用夹爪时还需松开 Trigger、让摇杆居中。 |
| `PICO publisher exited during startup` | 查看 publisher 的具体异常；确认 PC Service 运行、头显唤醒，PICO 的 `Network=WORKING`、`Controller/Send` 已开启，必要时在头显内 reconnect。 |
| `PICO XR frame stale` / `ROS2 PICO stream disconnected` | 检查头显休眠、电量、网络和 PICO publisher。短时失效会保持目标，恢复后重新锚定；断流超时会退出。 |
| DAS 编码器返回 `-66.66` | 停止占用串口的进程，清空对应夹爪，执行 `scripts/hardware/calibrate_das_finger.py`；完整命令见操作指南第 9 节。 |
| `ROS2 ... requires sourced ...` / `Package not found` | 激活 `Teleop`，source `/opt/ros/humble/setup.bash` 和 `ros2_ws/install/setup.bash`；检查消息包是否已构建。 |
| `CXXABI_1.3.15` / `libstdc++` 导入失败 | 检查是否把系统库预加载到 Conda；执行 `unset LD_PRELOAD` 后按操作指南重新准备环境。 |
| `planned CPU affinity is unavailable` | 本机可用 CPU 与配置不符；核对 `runtime.cpus`，按实际 CPU 编号配置。 |
| `collection or offline export is active` | 同一输出目录已有采集或导出；先正常结束冲突进程。不要删除锁文件来绕过互斥。 |
| `recording config differs from active devices` | 新录制的设备参数与运行中设备不同；恢复原配置，或停止设备后用新配置重新启动。 |
| `output bag already exists` / `export already exists` | 输出受保护；需重导出时先移走对应 `data/` 或 `final/`，保留 `state/` 与 `vision_*/` 原件。 |
| 明显卡顿但没有异常 | 结合时间戳、序号缺口与诊断判断，检查 CPU 负载/温度、磁盘空间及写入速度、PICO 电量和网络。 |

以下命令只读取配置或系统状态，不连接机械臂：

```bash
python scripts/data/run_collection.py --print-effective-config
pgrep -af RoboticsServiceProcess
ls -l /dev/ttyFingerLeft /dev/ttyFingerRight /dev/finger_camera_left /dev/finger_camera_right
df -h .
```

保留完整启动命令、终端异常、相关 JSONL 和 Episode 的 `*_recorder.log`。
不要清理 `logs/marvin_scale_calibration.json` 或把尚未确认完整的采集原件当作临时日志删除。
