# PICO → Marvin 日常操作说明

本文用于完成首次部署后的日常启动、遥操、标定、NSP 使用和关闭。每次启动前仍须
执行急停、清场和机器人状态检查。

## 1. 启动前检查

1. 机械臂工作区无人、无障碍物，观察员在急停旁；
2. 机器人无错误且处于静止/低速状态；
3. Tool、A/B 映射和机器人 IP 没有改变；
4. PICO 显示 `Network=WORKING`，`Controller`、`Send` 打开；
5. `Switch w/ A Button` 关闭，头显和左右手柄保持唤醒；
6. 双 Grip、双 Trigger 松开，双摇杆居中。

启动 PC Service：

```bash
bash /opt/apps/roboticsservice/runService.sh
cd /home/zxcx/TeleOp/xr-marvin-teleop
```

## 2. 常用启动命令

### 普通 IK

```bash
python scripts/hardware/teleop_marvin_hardware.py \
  --enable-hardware \
  --confirmed-estop \
  --confirmed-joint-mapping \
  --confirmed-robot-model "M6S-Lite-CCS-680-B"
```

### 动态 NSP

```bash
python scripts/hardware/teleop_marvin_hardware.py \
  --enable-hardware \
  --confirmed-estop \
  --confirmed-joint-mapping \
  --confirmed-robot-model "M6S-Lite-CCS-680-B" \
  --nsp-lateral --nsp-max-angle 10
``` 
横向 NSP 的默认参数为：死区 `0.03 m`、满量程 `0.12 m`、角度速率 `20°/s`。
仅在需要标定方向时增加：

```bash
--nsp-lateral-sign-left -1
--nsp-lateral-sign-right -1
```

## 3. 手柄操作

| 操作 | 效果 |
| --- | --- |
| 左 Grip 按下 | 从当前手柄姿态和 A 臂 TCP 重新锚定，控制左臂 |
| 右 Grip 按下 | 从当前手柄姿态和 B 臂 TCP 重新锚定，控制右臂 |
| Grip 持续按住 | 手柄相对位姿映射到对应 TCP，持续求 IK |
| Grip 松开 | 对应手臂锁存当前反馈关节角并保持 |
| 双 Grip 松开后按 B | 双臂沿默认 3 秒余弦轨迹返回初始姿态 |
| 回位中按某侧 Grip | 取消该侧回位并重新开始遥操 |
| 双 Grip 松开后按 A（第一次） | 采集双臂自然下垂姿态 |
| 双 Grip 松开后按 A（第二次） | 采集双臂水平前伸姿态并保存 scale |

Grip 使用上升沿重新锚定，手柄绝对位置不会直接造成机器人跳变。B 在任一 Grip
按下时会被忽略；A 在 Grip 按下、回位运行或机器人非低速时会被忽略。

## 4. 夹爪操作

夹爪只有启动时提供 `--gripper-config PATH` 才会启用。闭合度范围为 `0`（全开）到
`1`（全闭），输入是增量控制：

- 对应 Trigger 扣下：增量闭合；
- 摇杆向后拉：增量闭合；
- 摇杆向前推：增量打开；
- 输入回中：保持当前位置；
- 闭合输入与打开输入同时存在：闭合优先；
- 若前后方向相反：使用 `--thumbstick-y-sign -1`。

夹爪目标最多按 `20 Hz` 下发，程序退出或 XR stale 不会自动开爪。


## 5. 正常关闭

1. 松开左右 Grip，确认双臂保持；
2. 停止手柄动作；
3. 在终端按 `Ctrl+C`；
4. 等待程序报告 idle/资源释放完成；
5. 确认日志文件已写入 `logs/`，再关闭 PC Service。

如果出现异常运动，先触发物理急停，再处理终端错误。不要用退出程序代替急停。

## 6. 日志与故障定位

程序启动时会打印会话日志路径，常见文件为：

```text
logs/marvin_hardware_<timestamp>.jsonl
```

可用命令目标或反馈回放：

```bash
python scripts/simulation/replay_marvin_log.py \
  logs/marvin_hardware_<timestamp>.jsonl --source command --headless

python scripts/simulation/replay_marvin_log.py \
  logs/marvin_hardware_<timestamp>.jsonl --source feedback --headless
```

排查时保留：启动命令、终端 traceback、错误码、日志文件和当时的 PICO 按键状态。
